# InsightFlow – Responsive SaaS Dashboard Website

InsightFlow is a modern responsive SaaS website built with HTML and CSS. It features a polished landing page, realistic analytics dashboard UI, pricing cards, testimonials, and business-focused design patterns inspired by real product interfaces.

## Features
- Responsive design
- Modern dashboard UI
- Fake chart components
- Pricing section
- Testimonials section
- Clean business-focused layout

## Built With
- HTML5
- CSS3
